- **Переименование внутренних имён** `zovi` → `yavka` (папка, ключи браузера, переменная

  черновик — нужен перенос старых ключей.

## 4. Перед выкладкой в интернет

Пока сайт работает только на компьютере автора — ссылку никому не отправить.

1. **Хранилище.** Сейчас приглашения — файлы в `data/`. На бесплатных площадках вроде Vercel файлы
   не сохраняются. Либо простой сервер (VPS), где файлы живут как дома, либо переезд на базу данных
   и облако для фото — правится только `storage.ts` и `uploads.ts`.
2. **Домен и HTTPS.** Без HTTPS на телефоне не работают микрофон и камера.
3. **Превью ссылки в мессенджерах** — картинка и заголовок (Open Graph) для `/i/<id>`.
4. **Уборка:** срок жизни приглашений, удаление приглашения со страницы автора, чистка
   неиспользуемых загрузок.
5. **Telegram-уведомления для каждого автора, а не в один чат:** кнопка «Подключить Telegram»
   открывает бота с кодом привязки, автор жмёт «Старт».

## 5. Не проверено руками

- Запись голосового и кружка прямо в браузере — через микрофон и камеру, на компьютере и телефоне.
  Загрузка готовым файлом работает. Возможно, понадобится перекодирование на сервере (ffmpeg), если
  записанное на одном устройстве не играет на другом.
- «Стереть слой» и убегающая кнопка — на настоящем телефоне.
- Telegram-уведомления.
- Внешний вид после ребрендинга на телефоне и на компьютере — скриншоты не снимались.

## 6. Известные неточности

- **Тексты по умолчанию в режиме компании — свиданочные** («Ты пойдёшь со мной на свидание?»).
  Лечится пресетами поводов (раздел 2).
- **Описание темы «Билет» — «Как контрамарка на свидание»** — не подходит для праздника.
- **Стикеры — системные эмодзи:** на разных телефонах выглядят по-разному. Вариант — набор
  Fluent Emoji 3D под лицензией MIT.
- **Автотестов нет** — основной сценарий проверяется руками.
