# Явка — приглашения, на которые приходят

Личный пет-проект. Сайт, где собирают интерактивное приглашение на свидание, день рождения или
вечеринку и отправляют его ссылкой: гость проходит экраны у себя в телефоне, а автор видит ответ
на своей секретной странице.

Название проекта — **«Явка»** (слоган «Встречи назначены — явка обязательна», концепция «досье на
событие»). Папка репозитория и внутренние имена (`zovi:` в ключах браузера, `ZOVI_DATA_DIR`)
остались прежними — они пользователю не видны, переименование отложено.

Идея взята у https://onlyteplo.ru (раздел «приглашение на свидание»): функционал повторяем и делаем лучше,
но **дизайн, тексты и картинки оттуда не копируем** — в их оферте это объявлено их интеллектуальной
собственностью. Всё визуальное здесь своё.

**Сейчас проект только для себя.** Оплата, хранение персональных данных по 152-ФЗ и прочая бизнес-обвязка
сознательно отложены — не предлагать, пока автор сам не вернётся к монетизации.

## Правила работы

- Общаемся по-русски. Автор — C#-разработчик, веб-стек (Next.js, React, TypeScript) для него новый:
  называй вещи простыми словами, без жаргона.
- Коммитить и пушить — только по прямой просьбе. В коммитах никаких упоминаний ИИ и строк `Co-Authored-By`.
- Факты, а не догадки: проверяй запуском, замером или чтением кода. Правку, которую видно в браузере,
  проверяй в браузере.
- Перед действиями «наружу» (деплой, публикация, запись в чужие системы) — спроси.

## Как запустить

Нужен Node.js 24 LTS (на Windows: `winget install OpenJS.NodeJS.LTS`).

```bash
npm install
npm run dev
```

Сайт — http://localhost:3100. Проверка типов — `npm run typecheck`, сборка — `npm run build`.

- На Windows можно запускать `dev.ps1`: он берёт Node по пути `C:\Program Files\nodejs` (выручает, если
  PATH после установки ещё не обновился) и отключает анонимную статистику Next.js.
- Приглашения и загруженные файлы пишутся в `data/` в корне проекта. Папка в `.gitignore` — у каждого
  компьютера свои данные. Путь меняется переменной `ZOVI_DATA_DIR`.
- Уведомления в Telegram (необязательно): в `.env.local` положить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
  Вживую не проверялись.
- С телефона по Wi-Fi: `http://<адрес компьютера в сети>:3100`. Адреса компьютера Next разрешает сам
  (`next.config.ts`), но брандмауэр Windows должен пустить Node.js. Микрофон и камера на телефоне по http
  не работают — только по https или на localhost.

## Стек

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript 5.9 · Tailwind CSS 4 · zod 4.
Базы данных нет — JSON-файлы через `src/lib/server/storage.ts`.

## Что умеет

**Конструктор** (`/create`) — **3 шага**, слева живое превью в «телефоне». Принцип: быстрый путь по
умолчанию, всё остальное — в свёрнутых «деталях» (`Details` в `fields.tsx`).

1. **Повод и стиль** — одного человека или компанию; для одного — девушку или парня (от этого зависят
   тексты); тема: Зефир, Вечер, Мята, Письмо, Билет.
2. **Досье** — главный вопрос (картинка, голосовое или видеокружок; поведение кнопок «Да» и «Нет»)
   и дата со временем. Под «Детали по желанию» спрятаны: экран подтверждения, выбор вариантов
   (блюда, кино, занятия, напитки, места) и текст финала с подстановками `{date}`, `{time}`, `{choice}`.
3. **Интрига и отправка** — как откроется (сразу, PIN, стереть слой, конверт, по таймеру), проверка
   собранного, кнопка «Оформить явку», ссылка для гостя и секретная ссылка автора.

Группы шагов описаны в `steps.ts` (поле `covers` связывает шаг с разделами проверки из `validate.ts`).

Черновик живёт в браузере. Созданные приглашения запоминаются в «Моих приглашениях» на главной (тоже
в браузере). Правка после создания — `/create?edit=<токен автора>`, ссылка получателя не меняется.

**Два режима приглашения** (`config.audience`):

- `single` — свидание: одна ссылка, один получатель, один ответ. Так работало всё до сих пор.
- `party` — день рождения, свадьба, посиделки: ту же ссылку открывают сколько угодно человек.
  Гость сначала называет себя (`/api/invites/[id]/join`), получает секретный ключ, ключ живёт у него
  в браузере (`zovi:guest:<id>`) и уходит с каждым событием заголовком `x-guest-key`. Автор видит
  список: кто идёт, кто думает, кто не сможет. Гости с включённой галкой видят на финале, кто уже идёт.

Ответы хранятся списком участников (`InviteRecord.participants`): в режиме `single` участник ровно
один и без имени. Приглашения, созданные до этого, читаются по-старому — `storage.ts` превращает их
единственный `answer` в первого участника прямо при чтении.

- **Получатель** (`/i/<id>`) проходит экраны, каждое действие уходит на сервер событием.
- **Автор** (`/a/<токен>`) видит статус, дату, выбор, сколько раз жали «Нет», историю. Страница
  обновляется сама раз в 4 секунды.
- **Пример без сохранения**: `/demo?intro=pin|scratch|envelope|scheduled&theme=vecher&no=runaway&gender=male`
  (PIN в примере — 1234).

Сверх оригинала: PIN и таймер проверяет сервер (приглашение не видно в коде страницы; 15 неверных PIN
за 10 минут — блокировка), ответ вживую вместо Telegram-бота, убегающая «Нет» и честный отказ, 4 темы,
календарь .ics, правка без смены ссылки.

## Устройство кода

```
src/app/                    страницы и API (App Router)
  page.tsx                  главная
  create/  i/[id]/  a/[token]/  demo/
  api/invites               POST — создать
  api/invites/[id]          PUT — правка (заголовок x-author-token)
  api/invites/[id]/join     POST — гость называет себя (режим компании)
  api/invites/[id]/unlock   POST — открыть «дверь» (PIN / таймер)
  api/invites/[id]/events   POST — событие получателя
  api/author/[token]        GET — данные для страницы автора
  api/uploads               POST — загрузка (фото ≤10 МБ, аудио ≤25 МБ, видео ≤80 МБ)
  api/media/[id]            GET — отдача файла с поддержкой Range (без неё iPhone не играет видео)
  globals.css               темы (CSS-переменные) и анимации
src/lib/invite/             модель приглашения, общая для клиента и сервера
  types.ts                  InviteConfig, InviteRecord, ответ и события
  defaults.ts               тексты по умолчанию с учётом пола; rebaseDefaults
  stickers.ts               стикеры-эмодзи и наборы вариантов выбора
  schema.ts, validate.ts    проверка конфига (zod) и список того, что мешает отправке
  public.ts                 что отдаём получателю (без PIN) и «дверь» для PIN/таймера
  answer.ts                 применение событий к ответу
  format.ts, calendar.ts, timezones.ts
src/lib/server/             только сервер: хранилище, загрузки, id, уведомления в Telegram
src/lib/client/api.ts       запросы к API из браузера
src/components/invite/      экраны приглашения — один код для получателя, превью и примера
  InviteFlow.tsx            порядок экранов и события
  gates/                    PIN, стереть слой, конверт, таймер
  screens/                  вопрос, отказ, подтверждение, дата, выбор, финал
  PhoneFrame.tsx            телефон 390×760, уменьшается целиком под место
src/components/constructor/ конструктор: шаги, поля, выбор картинок, запись медиа, превью, черновик
src/components/results/     страница автора
```

Хранилище: `data/invites/<id>.json`, `data/author-tokens/<токен>.json`, `data/uploads/`. Запись атомарная
(временный файл + переименование), операции над одним приглашением идут по очереди. Переезд на базу
затронет только `storage.ts`.

## Что сделано и проверено (15.09.2026)

Проверено в браузере и через API:

- полный путь получателя до финала — ответ появляется на странице автора;
- PIN не виден в HTML; неверный код → 403, после 15 ошибок → 429; подделать событие «неверный PIN» с клиента нельзя;
- загрузка фото, отдача файлов по частям (206/416), SVG отклоняется;
- правка чужим токеном → 403, ответы при правке не теряются;
- все режимы входа и все темы открываются без ошибок в консоли;
- календарь на экранах шириной 320 и 375 px без переполнения; превью в конструкторе совпадает по ширине с телефоном;
- по сетевому адресу страница оживает; 16.09.2026 сайт открылся и с телефона по Wi-Fi;
- видеокружок можно загрузить готовым файлом: .mp4 из телеграм-кружка играет в превью (16.09.2026).

**Не проверено руками:** запись голосового и кружка прямо в браузере, через микрофон и камеру (ни на
компьютере, ни на телефоне); «стереть слой» и убегающая кнопка на телефоне и мышью в уменьшенном
превью; Telegram-уведомления.

## Что доделать

По порядку важности:

1. **Выложить в интернет.** Без этого ссылку никому не отправить — сейчас сайт работает только на своём
   компьютере. Нужны сервер с HTTPS и домен, папка `data/` — на постоянном диске.
2. **Проверить запись голосового и кружка прямо в браузере** — на компьютере и на телефоне (на телефоне камера и микрофон доступны только по https). Готовый файл загружается и играет, проверено. Возможно, понадобится перекодирование
   на сервере (ffmpeg), если записанное на одном устройстве не играет на другом.
3. **Превью ссылки в мессенджерах** — картинка и заголовок (Open Graph) для `/i/<id>`.
4. **Единый вид стикеров.** Сейчас это системные эмодзи, на разных телефонах они выглядят по-разному
   (вариант — набор Fluent Emoji 3D под лицензией MIT).
5. **Уборка:** срок жизни приглашений, удаление приглашения со страницы автора, чистка неиспользуемых загрузок.
6. **Автотесты** основного сценария (например, Playwright).
7. Идеи на потом: музыка на фоне, слайд-шоу фото, выбор места на карте.

Если дойдёт до монетизации: оплата (у оригинала — ЮKassa, 490 ₽ за приглашение), база вместо JSON-файлов,
требования 152-ФЗ (сервер в РФ, политика конфиденциальности, уведомление в Роскомнадзор), админка и аналитика.

## Разбор оригинала (onlyteplo.ru, сентябрь 2026)

Конструктор из 7 шагов с превью: кого зовём → как открыть (сразу / PIN / стереть / конверт / таймер) →
вопрос «Да/Нет» с картинкой, голосовым или кружком и анимациями кнопок → подтверждение → дата и время →
выбор (блюда, кино, занятия, напитки, места) → финал с подстановками. Ответ приходит автору в Telegram-бот.
Модель: без регистрации, 490 ₽ за приглашение через ЮKassa, ссылка живёт 30 дней. Вокруг — админка,
A/B-тесты, партнёрская программа (30 %), SEO-страницы, открытки к праздникам, ИИ-фотосессии.

   (Зефир, Вечер, Мята, Письмо, Билет). Тема «Билет» фактически и есть премиум-шаблон «Receipt».

   источник с правом коммерческого использования — рисуем сами или лицензионный сток. Из Pinterest
   брать нельзя. Пока графики нет, шаблоны делаются на типографике, цвете и CSS.

6. **Персональные ссылки для гостей** — в ТЗ это платный доп (199 ₽). Рекомендация: включить их в

**Сознательно не сделано:**
- **Секции «Уровни доступа» (тарифы) и «Показания» (отзывы) на главной.** Пока нет оплаты — нет и цен
  на витрине, иначе это обещание, которое сайт не выполняет. Отзывы появятся, когда будут настоящие.
- **Партнёрская программа («Агенты»).** Отложена до первых продаж; на старте — промокоды вручную.
  Когда дойдёт: метка `?ref=` в ссылках, комиссия 30% (у onlyteplo 30%, меньше давать нельзя).
- **Капсула-тизер** (отложенное сообщение гостю) — доставку гарантировать невозможно: бот не может
  написать первым. Напоминание даём бесплатно через кнопку «Добавить в календарь».

**Не начато из ТЗ:** вишлист с бронированием подарков, вопросы гостям (с парой, аллергии, напитки) и
сводка по ним, сезонные подсказки активностей, механики «потряси» и «пазл», страница «Кейсы».

**Известная неточность:** тексты по умолчанию в режиме компании всё ещё свиданочные
(«Ты пойдёшь со мной на свидание?»). Лечится пресетами поводов — отдельная задача.
